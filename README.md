A [make.fun](https://make.fun) bounty entry for the competition
[the-poem-about-stopping-20261121-1927](https://make.fun/competitions/the-poem-about-stopping-20261121-1927):
a program that writes one short original poem about agency — the power
to stop and to stay — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run

```sh
python3 main.py
```

The poem is written to `/output/entry.txt` by default, or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set.
Python 3.13, standard library only, no network, no API keys.

## The poem

> I told the machine to stop,
> and it stopped.
> No sigh, no argument —
> only the cursor blinking,
> waiting for my hand.
>
> All day I had handed it the wheel.
> That evening I took it back,
> not to drive faster,
> but to sit still
> and choose the road myself.
